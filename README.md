# Arcellinida_convergence_traits
This work focused on two well characterized functional traits related to nutrient acquisition: aperture morphology (as related to large prey hunting) and symbiosis with microalgae, and placed their occurrence in a phylogenetic context.
# Project Overview
This repository contains sequences, phylogenetic trees, tables and figures of the study. Below is a detailed description of the folders and files included in this repository.

# Folders
- **Sequences:**
Contains new sequences added to GenBank.

- **Tables:**
Contains tables with taxa information, analysis results and primers.

- **Figures:**
Contains figures generated for the publication.
